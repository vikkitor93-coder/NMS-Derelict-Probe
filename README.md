# NMS Derelict Probe

Read-only No Man's Sky derelict-freighter research/modding toolkit.

Current stable package: **v0.3.21**. The full source package, updater manifest, research corpus, tests, and AI handoff are published through this repository. Future versions can be installed from the pyMHF companion GUI with **Check / install GitHub update** and take effect after restarting NMS Derelict Probe.

The project does not hot-patch a running update: the updater backs up the current managed source, replaces the source package, and requires a restart.
